# 安装与升级

## 选择发行文件

官方发行页提供两种文件：

| 文件 | 适合谁 | 特点 |
| --- | --- | --- |
| CloudDock-1.0.0-Setup-x64.exe | 大多数用户 | 安装到当前 Windows 用户，创建开始菜单入口，支持软件内安装更新。 |
| CloudDock-1.0.0-Windows-x64.zip | 希望随身携带或不安装的用户 | 解压后运行 START.cmd 或 CloudDock.exe；可以检查更新，但不自动替换自身。 |
| CloudDock-1.0.1-beta.1-Setup-x64.exe | 愿意验证新功能的用户 | 测试版安装包；安装前先退出云屿，建议先备份个人数据目录。 |
| CloudDock-1.0.1-beta.1-Windows-x64.zip | 希望先用独立数据目录试用的用户 | 解压后使用，不会替换已有安装版。 |

请只从 [官方 Release](https://github.com/mouse0901/cloud-dock-releases/releases/latest) 下载，并对照同页的 CHECKSUMS.sha256 核验文件。
测试版请到 [v1.0.1-beta.1 发布页](https://github.com/mouse0901/cloud-dock-releases/releases/tag/v1.0.1-beta.1) 下载；正式版仍是 1.0.0。

## 安装版

1. 退出已运行的云屿。若主窗口关闭到了托盘，请在托盘菜单选择“退出云屿”。
2. 运行安装程序，按提示选择程序目录和数据目录。
3. 程序目录与数据目录不能互相包含。程序目录只放应用文件；数据目录保存配置、登录会话、任务状态、浏览缓存和下载默认位置。
4. 缺少 WebView2 Runtime 时，安装程序会提示安装 Microsoft WebView2 Runtime。
5. 完成后从开始菜单或桌面入口打开云屿。

安装按当前 Windows 用户生效，不要求管理员权限，也不需要自行配置 Python。

## 从旧便携版迁移

1. 在旧版托盘菜单选择“退出云屿”。
2. 启动安装版，在“从便携版导入”中选择旧 CloudDock.exe 所在的目录。
3. 导入会复制设置、当前 Windows 用户可解密的登录会话和任务记录。
4. 导入不会移动下载文件、同步文件或云端文件，也不会删除旧目录。
5. 导入后的同步规则默认暂停。先核对账号、本地位置和云端位置，再在“同步与备份”中继续启用。

不要把自己的数据目录、便携版 data 目录或包含会话的文件夹直接发给别人。分发时请使用干净的安装包或 ZIP。

## 覆盖升级

安装新版前不必卸载旧安装版。运行新版安装程序后，云屿会请求已有实例正常保存并退出；仍在传输、写入或核对的任务会阻止替换，避免破坏任务状态。

软件内更新会先校验已下载的安装包，并为程序文件创建恢复点。若安装明确失败，程序会尝试恢复旧版本；个人设置、下载文件、同步目录和云端数据不会被自动回滚。

## 卸载

卸载会删除程序、开始菜单入口和属于当前安装目录的开机启动项。数据目录、下载文件、同步文件与云端文件会保留。重新安装同一 Windows 用户下的云屿时，可以重新选择原数据目录继续使用已有设置。

## 常见问题

### Windows 显示未知发布者

当前版本尚未取得 Windows Authenticode 代码签名。请确认安装包来自官方 Release，并用 CHECKSUMS.sha256 验证文件哈希后再继续。

### 启动后白屏或提示 WebView2

确认 Windows 已安装 Microsoft WebView2 Runtime，再重启云屿。问题持续时，可在“设置 → 关于与更新”导出诊断并在反馈中提供脱敏内容。

### 能否把已安装目录复制到另一台电脑

不建议。安装版包含当前用户的数据位置和 Windows 用户加密的会话，复制程序目录不能安全迁移账号。另一台电脑请重新安装并使用自己的账号登录。
