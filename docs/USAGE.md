# 使用指南

## 首次连接网盘

1. 打开云屿，在左侧“我的网盘”选择百度网盘或夸克网盘。
2. 选择连接账号，并按窗口提示用对应 App 扫码或授权。
3. 授权完成后，云屿会读取当前账号允许访问的目录和容量信息。
4. 每个人应使用自己的账号。多个账号之间可以在“我的账号”中切换、改名或移除。

切换账号前，云屿会暂停该网盘的同步并等待相关文件操作结束。原账号的本地任务和已下载文件会保留。

## 浏览与整理文件

- 双击文件夹进入；顶部面包屑、前进后退和上一级按钮用于导航。
- 在右上角搜索框中输入关键词：当前页筛选会即时显示；需要跨网盘搜索时按 Enter 并选择范围。
- 右上角可以切换网格/列表视图，并在显示选项中调节密度、网格大小和长文件名。
- 选择项目后使用工具栏或右键菜单下载、移动、重命名、删除或复制到另一个网盘。
- 空白处右键可以新建文件夹或固定当前位置。文件夹可用中键或右键在新标签打开。

删除操作会先尝试移入对应网盘回收站。恢复和永久删除在左侧“回收站”中进行；平台是否立即释放空间由网盘决定。

## 上传

1. 打开目标网盘和目标目录。
2. 点击“上传文件”，或把文件/文件夹拖入文件区。
3. 文件夹上传会先扫描清单，显示文件数量、目录层级和不可读项。
4. 核对目标账号与目标路径，选择同名处理方式后确认。
5. 在“传输”查看进度、暂停、继续、取消和逐项结果。

符号链接、联接、不可读目录和超出目录层级限制的内容会在扫描阶段阻止提交，避免上传到非预期位置。

## 下载

1. 在文件区选择一个或多个文件，使用右键“下载到…”或工具栏下载。
2. 第一次下载、下载文件夹和发生重名时，云屿会要求确认保存位置。启用“直接下载到默认位置”后，自己网盘或分享中的单个文件可以跳过重复的位置确认。
3. 在“传输”中查看速度、已完成大小、预计时间、暂停/继续、优先级和失败原因。
4. 完成后可在任务项中打开所在文件夹。

网盘会员权益、账号状态、平台接口、文件类型和网络链路共同决定实际速度。云屿不会承诺固定速度，也不会使用绕过平台限制的方式下载。

## 同步文件或文件夹

1. 打开“同步与备份”，选择新建同步。
2. 选择本地文件或文件夹、云端目录、同步方向和排除规则。
3. 查看预览：云屿会列出将新增、修改、删除或需确认的项目。
4. 确认后启用规则。首次启用建议先用小目录验证。
5. 打开任务详情可查看最近检查、变化清单、冲突、删除确认、事件记录和历史版本。

冲突不会自动覆盖。请在任务详情选择保留本地版本、使用云端版本、确认删除或暂时保留两端。解除同步只停止规则，不会删除两端现有文件。

## 使用分享链接

复制百度或夸克分享链接时，云屿会识别运行期间的新链接。主窗口最小化或隐藏到托盘时，默认会被唤起；此行为可在“设置 → 便捷操作”关闭。

识别后先核对分享内容，再选择浏览、下载、保存到链接收件箱或移除。云屿不会在检测到链接后自动下载，也不记录未被你确认收下的剪贴板链接。

## 通知、声音和托盘

- “设置 → 声音与通知”可独立设置上传、下载和异常提示音、通知、音量和免打扰。
- 自动同步成功保持安静；连续完成的任务会合并提醒。
- 关闭主窗口默认到托盘，后台传输和同步继续。真正退出请从托盘菜单选择“退出云屿”。
- “设置 → 运行”可打开开机启动；首次启用后，Windows 登录时会在后台启动云屿。

## 需要帮助时

先在“传输”或同步任务详情查看具体错误。若需要反馈，使用“设置 → 关于与更新 → 导出诊断”，并删除任何你不希望分享的环境信息。不要提交 Cookie、二维码、账号标识、文件名、绝对路径、分享链接或提取码。
