# 隐私与本地数据

## 原则

云屿以用户自己的网盘账号和本机文件为中心工作。账号会话、任务记录和同步规则不应被放入 Git 仓库、安装包、Issue 或公开日志。

## 数据存放位置

安装时会选择一个独立数据目录。该目录可能包含：

| 数据 | 用途 |
| --- | --- |
| preferences.json | 外观、通知、更新通道等个人偏好。 |
| sessions | 当前 Windows 用户加密的登录会话。 |
| activity.sqlite3 | 传输、同步、通知与操作记录。 |
| webview | WebView2 页面缓存和本地状态。 |
| work | 下载、上传、跨盘复制和更新使用的临时内容。 |

默认下载目录也可以在设置中调整。云屿不应把数据目录和程序目录混在一起。

## 登录会话

登录会话按当前 Windows 用户加密保存。其他 Windows 用户和另一台电脑通常无法直接解密。请不要复制自己的数据目录给其他人；分发软件时请使用干净安装包或便携 ZIP。

移除账号会删除云屿保存的该账号本地会话；不会删除网盘中的文件。已下载文件、同步目录和历史任务可能仍留在本地，应由用户按需要处理。

## 剪贴板与链接

云屿只在运行期间检测新复制的支持格式分享链接，用于唤起窗口或显示链接操作。它不会自动下载。只有当你明确选择保存时，链接和提取码才会写入链接收件箱；其中敏感内容会使用当前 Windows 用户的加密保护。

## 诊断与反馈

软件内“导出诊断”旨在仅导出版本、状态和统计类信息。它不应包含 Cookie、账号标识、文件名、文件路径、分享链接或原始日志。导出前仍请自行检查内容，并在公开反馈前继续脱敏。

## 更新请求

安装版可检查稳定或测试更新通道。更新清单公开托管在 GitHub，并使用 RSA 签名验证；安装文件在使用前核对 SHA-256。更新检查本身不可避免地会与更新托管服务发生网络连接，该服务可按其自身规则处理网络连接信息。

## 你可以控制的内容

- 在“我的账号”移除本地保存的账号会话。
- 在“设置”关闭自动检查、自动下载、声音、通知、托盘唤起和开机启动。
- 在“同步与备份”暂停或解除同步规则。
- 清理本地下载、工作目录和已完成任务记录前，先确认不再需要断点续传或核对信息。

若发现隐私或安全问题，请阅读 [安全说明](../SECURITY.md)，且不要在公开 Issue 中提交凭据或私人文件信息。
