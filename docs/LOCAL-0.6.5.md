# 0.6.5 本地修复与验证

本轮优先处理下载瓶颈、主题连点崩溃、界面恢复与删除反馈。没有执行 Git push、创建 Release 或修改更新通道。

## 实现

- 百度会员下载从固定单连接改为最多 8 个长分片；未知/普通账号最多 4 个。仍使用当前账号返回的百度 HTTPS 下载地址与权限，不引入第三方票据。会员状态保留在内部。
- 小短分片在本次真实 CDN 测试中出现 HTTP 403，完整测试导致回退。改为每连接一个长分片；遇到临时网络失败保留分片，拒绝并发时刷新一次后回退普通下载。16 连接实测也触发回退，因此没有选它为默认值。
- 深浅外观：标准 mask-size / mask-position 动画替代继承自定义属性动画；合并连点意图、设置超时、释放动画。仍有从按钮扩散的柔和边缘。不能从旧版崩溃转储证明唯一根因；本版通过原生实际点击验证。
- WebView2 主渲染进程异常重载页面；浏览器进程退出重建控件。GPU/辅助进程失败不误报成整个界面断开。60 秒最多自动恢复两次，后台保持运行，恢复页面位置。
- 删除预览立即打开核对状态，对话框展示具体失败原因；确认失败后要求关闭并刷新，原确认不会再次提交。文件服务错误不再误报成上传错误。意外错误写入脱敏本地诊断，并可从设置导出。
- 文件夹下载扫描从串行改成最多 4 路，最多 10000 项、64 层、10 分钟，取消会结束全部扫描工作。完整预览确认后才入队。
