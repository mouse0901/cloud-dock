云屿 Cloud Dock 1.0.1-beta.1 · Windows 本地测试版

安装程序：CloudDock-1.0.1-beta.1-Setup-x64.exe
便携版本：CloudDock-1.0.1-beta.1-Windows-x64.zip
需要 Windows 10/11 x64、.NET Framework 4.8、Microsoft WebView2。
安装程序按当前 Windows 用户安装，不需要安装 Python。缺少 WebView2 时会提示联网安装微软运行环境。

首次使用
1. 运行安装程序，选择程序目录与独立数据目录，两者不可相互包含。
2. 有旧便携版时先在托盘退出；在“从便携版导入”页选择旧 CloudDock.exe 所在目录。
3. 导入会复制设置、当前 Windows 用户加密的登录和任务记录；不会移动下载或同步文件，也不会删除原目录。
4. 导入后的同步先暂停。核对账号、两端位置后，在“同步”继续启用；以后使用安装版入口。旧独立备份功能已退役，其规则保持停用。
5. 没有旧版时，导入目录留空即可。每人登录自己的网盘账号。

安装与升级
- 程序目录只放程序；installed-data.txt 记录数据位置。数据目录含 preferences.json、sessions、activity.sqlite3、webview、work。
- 下载位置由设置选择；已有自定义路径保持不变。便携版默认 data 与程序同级；桌面默认下载在数据目录内 downloads。
- 更新时重新运行新版安装程序。先请求当前实例正常保存并退出，后台未退出则停止安装，不强制杀进程。
- 卸载移除程序、安装入口和属于本安装目录的自启动项；保留数据、下载文件、同步文件和云端内容。
- 当前用户注册表仅保留数据位置，供重装找回；重新安装可以继续使用原配置。
- 当前用户 DPAPI 登录文件不能保证在其他 Windows 用户或另一台电脑解密。分发给朋友请发干净安装包或 ZIP，不要发自己的数据目录。
- 默认关闭窗口到托盘；在托盘菜单/设置“退出云屿”才停止后台。开机启动默认关闭，可在设置开启。

本版账号与维护
- 左下角“我的账号”可添加、改名、切换或移除账号；每个平台最多保存 5 个，一次连接一个。
- 切换前暂停传输并等待文件操作结束；同步先暂停，切回后手动继续。原账号任务和文件保留。
- 设置“运行”可导入导出个人偏好；不包含账号、文件位置、自启动、更新源或同步规则。
- 设置“关于与更新”可做运行检查、导出诊断、查看程序升级恢复点。
- 安装版内置更新会备份程序文件；明确失败时尝试恢复，安装结果不确定时等待核对。个人数据不回滚。

分享与下载
- 通过左侧“打开链接”或 Ctrl+Shift+L 打开百度、夸克分享；先查看文件，再选择保存位置。
- 剪贴板识别多条分享时可以选择；不会自动下载。新链接默认自动唤起窗口，可在“设置 → 便捷操作”单独关闭唤起。
- 只处理运行期间新复制的链接，不弹出启动前旧内容；同一链接 10 分钟内去重。需要再次打开时可用“打开链接”。
- 百度真实 SVIP/EVIP 优先使用百度 PCS 调度与匹配协议分片，失败回退；不承诺固定速度。

本版批量操作
- 点击“上传文件”可选择文件或整个文件夹，也可拖入。先核对完整分页清单，再确认上传。
- 一次上传最多 10000 个文件和文件夹、32 层子目录。符号链接、联接和不可读目录会阻止此次扫描。
- 多选项目后可“移动到…”或“批量重命名”；F2 对多选打开批量改名。顺序编号按照当前显示顺序，保留扩展名。
- 同名策略支持跳过与保留两份；文件夹同名时不合并，整体跳过或创建带编号的新文件夹。预览后新发生冲突会停止/跳过该项。
- 完整结果保存在“传输 → 批量操作记录”。退出中断的云端移动/改名会标记未执行或待核对，不会自动重复提交。
- 夸克跨目录移动遇到重名时可能先改名再移动；第二步失败时结果会标明中间名称，请按记录核对。
- 涉及活动同步或未完成传输的项目会被阻止，先暂停相关规则并处理任务。

浏览与传输工作区
- 最多 10 个标签页；Ctrl+T 新建、Ctrl+W 关闭、Ctrl+Tab 切换，右键/中键打开文件夹到新标签。
- 标签位置与选择仅保留在当前运行期间，不在退出后存储；账号改变时清除旧浏览位置。
- 单个目录最多定位 1000 页，搜索定位最长等待 60 秒；文件变化后需要重新搜索。
- 工具栏“显示选项”可调整列表密度、网格大小、长文件名；悬停与信息栏可看完整名称。
- 传输按本次创建的任务分组；旧版记录缺少分组标识的保留为单项，避免把同名目录混合。
- 整组操作一次最多 500 项；筛选只影响显示，组按钮会处理该组中所有适用任务。
- “继续整组”处理暂停项，“重试失败项”处理失败项；已完成、已取消和需重新创建的任务不会重复提交。
- 优先级只影响同一网盘、同一传输方向的等待队列，同级按原入队顺序执行。
- 上传提交前可以暂停，继续时从头上传；进入云端提交/核对阶段后先完成结果核对。
- 预计剩余时间由当前速度估算，受网络变化影响；暂停、失败和准备阶段不保证预计时间。
- 磁盘写入失败：释放原盘空间后重试可继续断点；另选位置会从头下载。历史任务的旧临时文件可能保留，确认新文件完整后再自行清理。

此前功能
- 同步任务详情新增“管理历史空间”。先暂停任务，核对占用，再选择每个文件至少保留数量与最近天数，预览后确认。每次最多 20 个历史文件。
- 本地历史清理为永久删除，确认页会明确列出文件；云端历史移入网盘回收站，是否立即释放容量由网盘决定。
- 未完成发布仍引用的历史全部受保护。旧云端历史没有原始路径索引的只统计不清理，避免不同目录中的同名文件混淆。空的历史目录暂时保留。
- 设置中提供签名更新、更新通道、自动检查和自动下载。诊断报告不包含 Cookie、账号标识、文件名、文件路径、分享链接或原始日志。

第四、五批新增功能
- 新建文件夹、固定当前位置移至文件区右键菜单；支持空白处、单个文件和多选菜单，以及菜单键 / Shift+F10。
- 设置 → 关于与更新 → 完整更新日志，离线查看 16 个版本；完整版本号精确匹配，其余文字搜索更新内容。
- 同步 → 任务详情 → 变化清单，只读取并比较两端；确认冲突前可核对大小、时间与版本信息。
- 历史版本需要先暂停任务；恢复始终生成带“恢复”后缀的本地副本，原文件与历史保留。副本仍位于同步范围，确认内容后继续同步时可能上传此副本。
- UE、开发、媒体排除模板可以编辑。排除清单统计被剪枝的目录本身，不展开排除目录内的文件。
- 全盘搜索可选全部已连接网盘，搜索结果显示来源与路径；某一端失败不清空另一端结果。
- 右键 → 复制到另一个网盘：选择目标与同名策略，预览后确认。最多 2000 项、32 层；同名文件夹不合并，跳过或整体保留两份。
- 跨盘复制通过本机下载暂存再上传，一次一个任务；需要足够本地空间和目标网盘容量。原文件始终保留。
- 暂停、重启后继续会核对原账号、源版本和目标位置；已完成项不重复。移除任务只清理本机自有暂存，已写入云端的文件保留；异常留下的 .clouddock-copy- 临时文件需核对后自行处理。
- 链接收件箱只保存明确收下的链接，不记录其他剪贴板内容。支持备注、提取码编辑、继续浏览、移除和清空；链接与提取码用当前 Windows 用户加密。
- 创建分享、分享转存目前标为实验功能，需用户明确确认；不会自动发布或自动转存。百度分享支持 1/7/30 天，夸克当前 7 天，均设置 4 位提取码。
- 分享转存到选定位置下新建的独立文件夹，避免混入已有同名文件。响应不确定时显示待核对位置，不自动重复提交。
- 真实账号跨盘复制、创建分享和转存尚未完成验收；自动测试验证了请求与操作流程，不代表平台对所有账号都开放这些能力。

使用边界
- 下载支持会话内暂停/继续；可恢复的任务退出后保留断点，重新连接原账号并校验文件版本后继续。无可用断点或版本变化时需要重新下载。
- 文件夹与单文件同步有双向/上传/下载三种方向；云端通过轮询检查，删除与冲突由用户处理，不是块级增量同步。
- 长时间真实断网、大规模目录、Windows 实际重启登录、多电脑同时修改还需进一步验收。
- 夸克真实上传/双向同步仍待容量充足的账号验收；不保证下载速度。
- 旧独立备份功能已移除，旧规则和文件保留；这些旧文件仍通过原目录手动管理。本版历史恢复与空间管理针对“同步”产生的历史。
- 安装版支持软件内检查、下载和安装更新；便携版暂不自动替换程序。当前安装包尚未取得 Windows Authenticode 代码签名；如 Windows 显示未知发布者，请只从官方 GitHub Release 下载并核对 SHA-256。

卸载不会删除你的文件，但更换电脑或重装 Windows 前请自行备份数据与重要文件。

声音与通知
- 设置 → 声音与通知，可分别设置上传/下载/异常声音、通知、音量与免打扰。下载与上传声音默认开启，异常声音默认关闭，音量 30%。
- 分享链接下载也计入完成提醒；连续完成合并，暂停与取消不响，自动同步成功保持安静。
- 桌面提醒使用云屿自己的卡片，不写入 Windows 通知中心。最近 100 条提醒在左侧“通知”中查看。关闭桌面通知不影响声音；免打扰期间均不弹不响，记录保留。
